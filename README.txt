Dental Studio Lumen — statični sajt (portfolio)

Sadržaj:
- index.html        glavna i jedina strana
- images/           fotografije (hero, tim)

Kako da postaviš na GitHub Pages:
1. Napravi novi repozitorijum (npr. "lumen").
2. Otpremi index.html i folder images u koren repozitorijuma.
3. Settings -> Pages -> Source: "Deploy from a branch", grana main, folder / (root).
4. Sajt će biti na https://<tvoj-nalog>.github.io/lumen/

Napomene:
- Izmišljeni brend za portfolio. Pre pravog korišćenja zameni [ADRESA] i [BROJ TELEFONA] u index.html.
- Forma je samo primer i ne šalje ništa. Za pravo slanje treba backend ili servis (npr. Formspree).
- Fotografije su stock; proveri licencu pre komercijalne upotrebe.

Koncept i dizajn: Milica Cucić, MC Design.
